# Проектирование архитектуры ИС: конспект к контрольной

Оцифровка пяти фотографий тетради. На них есть записи по всем 11 вопросам раздела I «Разработка ИС», но не по всем деталям из методички. Разделы II–IV не перенесены.

[Раздел I. Разработка ИС](notes/01-Разработка-ИС.md) — вопросы 1.1–1.11, с. 4–21 методички.

Основной текст взят из тетради. Сокращения раскрыты, схемы переведены в списки и последовательности, заголовки и нумерация сверены с приложенной методичкой `6sem_Proekt_Arkh_Is_Metodichka.pdf`. Номера фотографий идут в порядке вложений. Если нужны подробности, которых нет в тетради, смотри указанные страницы PDF.

## Как тренироваться

Напиши: «Погоняй меня по конспекту: один вопрос за раз, без подсказок до моего ответа». После каждого ответа можно сверить, что уже получилось и что нужно повторить. Если важно не выходить за границы записей, добавь: «Спрашивай только по тетради».
